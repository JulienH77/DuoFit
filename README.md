# DUO FIT — V002

Application web sportive mobile-first conçue pour le suivi en duo (Julien & Arina).

## Changements apportés
- **Visuel** : Suppression des images SVG pour une interface textuelle épurée et réactive.
- **Profils** : Passage aux utilisateurs Julien & Arina.
- **Réinitialisation** : Données de départ vierges (aucune séance enregistrée).
- **Exercices dynamiques** : Ajout d'un formulaire pour créer de nouveaux exercices avec nom, catégorie, description et points.
- **Calendrier** : Pastilles de suivi sous chaque date (bleu pour Julien, rose pour Arina).
- **Données** : Éditeur/Importateur JSON intégré pour faciliter la modification manuelle ou la migration vers Supabase.
